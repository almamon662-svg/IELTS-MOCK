📕 Cambridge IELTS PDF Import

Upload one complete Cambridge IELTS PDF. The importer will extract the text and automatically create four published module lessons: Listening, Reading, Writing and Speaking.

How it works

The system reads the PDF page text, detects IELTS skill headings, groups pages into the four modules, and saves each module as a published lesson. You do not need to upload four separate files.

For scanned/image-only PDFs, automatic text detection may not work. A text-based PDF works best.
